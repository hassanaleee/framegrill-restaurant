# FrameGrill Restaurant Website

A modern full-stack restaurant website built using React, Tailwind CSS, Express.js, and MongoDB Atlas.

## Features

- Dynamic food menu
- Cart & checkout system
- MongoDB database integration
- Responsive premium UI
- WhatsApp ordering support
- Admin-ready backend structure
- REST API integration

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Vite
- TypeScript

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

## Installation


Frontend:
```bash
npm install
npm run dev
```
Backend:
```bash
cd server
npm install
npm run dev
```
